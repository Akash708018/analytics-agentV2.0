# B2 — Pack framework + tool registry + core pack

## Built
- `backend/packs/models.py` — Pydantic pack schema (extra fields forbidden; SQL in any pack
  text or preset refused; tool ids namespaced; descriptions ≤200; forks need a reason with a
  suggestion; template shapes need their fields).
- `backend/packs/loader.py` — discovery, `extends` merging (core always first, cycles refused),
  cross-reference checks (concepts, forks, sources, rules).
- `backend/packs/detector.py` — binds columns to concepts, scores marketing sources and
  domains with evidence (matched columns, score). A supporting source (orders) is listed but
  does not by itself make a file "marketing".
- `backend/tools/registry.py` — gating (needs_domain / needs_data / active), LLM schemas for
  active tools only (core analyses share one `core_analyze` schema), token estimate,
  `compile_errors` (every tool's `base_analysis` is a registered engine analysis).
- `packs/core/pack.yaml` — measure types, `tax_basis` / `fiscal_year` / `timezone` forks,
  open-record flag rule, `no_sum_of_rate` + bounds, PII classes + `min_group_size` 5, India
  festival calendar (6 events, `confirm_yearly`), and the 16 measure-word classes.
- `packs/marketing/pack.yaml` — sources (paid_ads, ga4, search_console, email, social, orders)
  and 51 concepts. Templates/forks/tools are B3.
- `engine/contract/suggest.py` — its 16 keyword sets now come from the core pack.
- API 0.2.0: uploads, dataset, profile, cleaning, domains, contract, tools, packs live.
