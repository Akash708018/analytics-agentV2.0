# B5 — interpretation filter + marketing playbooks

## Built
- `backend/rules/interpret.py` — 9 deterministic rules over answer text + tool trace:
  no_sum_of_rate, no_cross_source_conversion_sum, bounds, consequence_not_cause,
  correlational_only, required_stratifier, measurement_change, small_sample, festival_confound.
  Always on: the five data-driven ones; pack/playbook rules add the rest.
- `backend/playbooks/agent.py` — planner (1 LLM call: playbook + slots, or none) → engine runs
  the playbook's tool steps (no LLM) → explainer (1 LLM call; sees figures and caveats, never
  rows) → figure check (v1 `verify.py`) + interpretation check → ONE correction call if either
  fails → unresolved items become `flags`. No playbook: tool calling over ACTIVE tools only
  (≤4 calls).
- `backend/llm/provider.py` — `ScriptedLLM` (tests/benches), `EngineLLM` (v1 providers with
  failover; a failover never re-runs a tool). Turns now run the agent when a model is
  configured; otherwise still `agent_not_wired`.
- 6 playbooks (marketing pack 0.4.0): why_roas_dropped, where_is_spend_wasted,
  why_organic_traffic_dropped, did_the_campaign_work, funnel_leak, email_health.
- `rate_mix_shift` (tier 9): v1's `mix_shift` handles means only and refused CVR (a ratio);
  the Simpson check for a blended rate weights by denominator share. Hand numbers first:
  A 10/100→12/100, B 2/100→9/300 → overall 6%→5.25%; rate +1.5, mix −2.0, interaction −0.25.
