# B1 — API contract v0.1 + sessions

Written before any B1 code ran. Real output pasted beneath each command at the end.

## Design (decisions D-B1-* in `docs/decisions.md`)

- Contract-first: every endpoint's request/response model, with examples, is declared in
  `backend/api/schemas.py` before its logic. `docs/api/openapi.yaml` is exported from those
  declarations (`uv run python -m backend.api.export_openapi`) and committed;
  `backend/tests/test_openapi_drift.py` fails if the two differ.
- Layers: `backend/sessions/store.py` (sqlite3, `state/sessions.db`) → `backend/services/`
  (all logic) → `backend/api/` (thin FastAPI routes). MCP will call the same services.
- Live in B1: sessions (create/get/ui-state/delete), turns (create/get/list), health, version.
  Every other endpoint answers **501** `{"error": {"code": "not_implemented", "milestone": ...}}`
  while its 200 shape and examples are already in the spec, so Codex can mock.
- A turn runs once in a background worker; `GET /turns/{id}` only reads the stored row. A turn
  found `running` at startup is marked `interrupted`, never re-run. B1's default runner has no
  agent (B5): it records an `error` event `agent_not_wired` — honest, not a fake answer.
- ui_state: ≤256 KB serialized (413), and rejected (422) if it holds API-key-shaped strings,
  emails/phone numbers, or row-shaped arrays (≥20 objects with identical keys).
- Sessions expire after 30 days without activity (sliding: every read/write extends).
