# B3 — marketing pack: knowledge + Tier-1 tools

## Built
- `packs/marketing/pack.yaml` 0.2.0: 20 metric templates (13 ratio-of-sums the engine computes;
  distinct-count, weighted-mean, semi-additive and derived marked `engine_ready: false` and
  refused with the reason), 6 forks (conversion_source, roas_revenue_basis, attribution_window,
  email_rate_denominator, cac_scope, gsc_aggregation), 3 validity rules, 6 interpretation rules,
  4 dated + sourced changelog entries, 20 Tier-1 tools as step presets over engine analyses.
- `backend/tools/runner.py`: resolves `@concept`, `@metric:<template>`, slots, `@param:x[=default]`,
  festival dates; compiles approved validity rules and structured filters (between, date_range,
  person-supplied terms) into the engine's guarded `where=` from quoted identifiers and
  validated values; runs each step through the engine's own `_produce` (contract gate, scope,
  refusals); returns figures with provenance, chart-ready series, filters/rules/forks applied,
  and caveats (engine notes, flags, small groups suppressed, festival_confound,
  measurement_change, UTM checks).
- Services + API 0.3.0: metric templates/approve (a template becomes a contract ratio measure
  and the contract a new version), validity rules list/approve, fork answers, tool run.
